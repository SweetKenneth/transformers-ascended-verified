each one came from. That claim is only inspectable if the earlier trees are still
readable at stable URLs. This repository is one of those trees.

## What this repository is not

- Not the SHPBL system. That is `SweetKenneth/shpbl-master`.
- Not a capability accepted into an external catalogue. Those are the
  `shpbl-*` implementation repositories referenced from the canonical README.
- Not maintained, supported, or representative of current SHPBL behaviour.
- Not evidence that any third party reviewed, certified or endorsed this code.
